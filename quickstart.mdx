本页帮助你用最短流程开始使用 Better Gate。

## 1. 注册并验证邮箱

创建账号后，请先完成邮箱验证。验证邮件可能会进入垃圾邮件或广告邮件文件夹，如果没有收到，可以在页面上点击重新发送。

## 2. 进入工作区

首次进入后，你会默认拥有一个个人工作区。

如果你是自己使用，可以直接继续使用个人工作区。

如果你要和团队一起使用，可以从左上角工作区切换器创建组织，或点击 **加入已有组织** 通过邀请链接加入团队。

## 3. 准备预算

个人工作区需要先充值。

组织工作区通常由组织统一充值，管理员可以给成员分配预算。成员创建的组织 Key 会消耗自己的成员预算。

## 4. 创建 API Key

进入对应工作区后，打开 API Key 页面，创建一个新的 Key。

基础设置通常只需要：

- Key 名称

- 渠道分组

- RPM / TPM 等速率限制，按需设置

高级选项可以先保持默认，等你有明确需求时再调整。

## 5. 接入你的应用

在你的应用或工具里使用 Better Gate 提供的 Base URL 和 API Key。

一个典型流程是：

\`\`\`text

选择工作区 -\> 准备预算 -\> 创建 API Key -\> 接入应用 -\> 查看用量

\`\`\`

## 6. 查看用量和账单          

请求发出后，你可以在用量页面查看消耗、模型、状态和错误信息。

如果充值成功但还没有开票，可以在账单页面申请发票。已开票记录支持预览和下载。
